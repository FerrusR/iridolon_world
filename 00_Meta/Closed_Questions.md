## Космология / метафизика
- [x] ✅ Природа **[[Сердце|Сердца]]** — природный **родник жизни и магии**, питается многомирьем; **с Нечто не связан** (ни родства, ни цикла). Физика — тайна для игроков навсегда.
- [x] ✅ Механизм **сковывания** — боги в цейтнот **бросили себя клеткой-изоляцией** вокруг Нечто в городе; цена — стали узниками затычки и стираются в неё (часы кампании). См. [[Катастрофа]].
- [x] ✅ Связь **Нечто и Сердца** — её нет; роднит лишь место (Нечто в руинах **над** Сердцем).
- [x] ✅ **Пра-история (до богов):** внешний враг — **демоны из ближнего мира**, вторгшиеся по «дороге демонов». Пятёрка отняла у их лидера **сифон** (демонский инструмент выпивания миров → [[Опустошитель]]), прошла к [[Сердце|Сердцу]], **вознеслась** и уже божественной силой отогнала демонов и **заперла дорогу**. Сердце — родник, не оружие (тема №1, см. [[Архитектурные_приоритеты]]). Истребление прорвавшихся заняло **долгие годы**; горстка демонов уцелела, затаилась и осмелела после Катастрофы → [[Культ Пепельной Матери]]. Осталось: **роль демонов** (минорное участие/отсылка в одной арке; не основная тема). ✅ Связь с ancestries решена → [[Народы]] (тифлинги = след демонов; дроу = порабощённые демонами эльфы).
- [x] ✅ **Происхождение демонов — мастер-тайна (2026-08-14)** → [[Демоническая война]] («Кто такие демоны»), [[Опустошитель]], [[Народы]], [[Кадреш]]. Демоны — **бывшие смертные** другого мира: бежали от **завоевателя** (хотел покорить, не стереть), **выпили [[Сердце]] родного мира** досуха и подняли этой силой **корабли-ковчеги** сквозь эфир; родину тем убили. **Межмировой эфир переделал их в демонов**; с тех пор скитаются и **пьют встречные миры на топливо** (в Элинваль пришли за его Сердцем). [[Опустошитель|Сифон]] строили именно под слив Сердца. **Тёмное зеркало пятёрки:** одни смертные у чужого Сердца вознеслись спасти свой мир — другие у своего выпили его, чтобы спастись самим. ⚠ Их завоеватель **≠ [[Катастрофа|Нечто]]** (иное «извне», фон «мир больше партии»). Осталось (листья): истинная форма/вид демонов для бестиария; кто завоеватель (к спеху не нужно).
- [x] ✅ **Кап — только на divine-магию, 3-я ячейка**; arcane/primal/occult не тронуты. Остаточная divine идёт **напрямую от ослабших богов** (инстинктивно питают жрецов); угасала постепенно, к лимиту пришла недавно. PC-жрец превышает кап **силой [[Проводник|Проводника]]** (думая, что это бог). См. [[Метафизика магии]], [[Пантеон]] т.2/т.7.
- [x] ✅ **Дорога домой Нечто — односторонняя** → [[Катастрофа]], [[Текстура выживания]]. Дорога, которой призвали [[Катастрофа|Нечто]], **разбита и односторонняя**; восстановить/найти её = цель финала (ветка «вернуть домой» в [[05_Campaign/_Index|матрице 2×2]]). Слуги Нечто **просочились** в мир через **прорехи дрейфа** ([[Текстура выживания|Чужие]]), не дверью. Открыто (→ [[Open_Questions]]): что именно в его родном мире.

## Дрейф реальности
- [x] ✅ Источник дрейфа — **призванное Нечто**, не исчезновение богов.
- [x] ✅ Якорь стабильности — **присутствие многих разумных** (консенсус), не буквальный взгляд.
- [x] ✅ Противоречие «юг»: **узлы держат идентичность/климат, плывут рёбра** (путь между). В юг можно прийти, идя не на юг.
- [x] ✅ Механизм «**сковывание = печать, дрейф = течь**»: уход/освобождение богов → дрейф к 100%.
- [x] ✅ **Дрейф ускоряется** = мир умирает (часы кампании).
- [x] ✅ **Градиент по радиусу**: у центра дрейф/чуждость сильнее всего.
- [x] ✅ «Твёрдых» Великих дорог **нет** — стабильность пути даёт **хоженость + число идущих** (цепочка присутствия). Народные истины об этом разнёс орден [[Удача (бог)|Лире]] (см. [[Дрейф реальности]], [[Удача (бог)|Лире]]).
- [x] ✅ **Якорит внимание, не разум; столбы-глаза Архимага (2026-07-04)** → [[Гильдия Навигаторов]], [[Дрейф реальности]]. Консенсус держит **внимание**, а не разум как таковой. Столбы-глаза [[Архимаг юга|Архимага]] работают на **divine-реликвиях со следом внимания бога** (эрзац-присутствие; тайна мастера, [[Арка 3]]). Столб = **навигатор наоборот**: навигатор процедурой *отвязан* от консенсуса (потому проходит сквозь дрейф и почти не якорит), а столб консенсус *подделывает*. Открыто (→ [[Open_Questions]]): животные/спящие как якоря, порог плотности.

## Гипотезы к проверке
- [x] ✅ **Город стоял над [[Сердце|Сердцем]]** — по вертикали: руины с Нечто на поверхности, **тайное Сердце глубоко под ними**. Игроки находят Сердце поздно и лишь тогда понимают, что оно было прямо под городом. Архимаги не знали, почему линии сходятся здесь.

  - [x] ✅ **№1 Становление и вознесение:** отряд в войну с демонами добыл [[Опустошитель|сифон]] (из ставки демонов; знание — от перебежчика [[Кадреш|Отступника]]), [[Время (бог)|Темпус]] + Отступник доработали его, **сознательно** вознеслись у [[Сердце|Сердца]], чтобы спасти мир.   - [x] ✅ **№2 Сразу после вознесения:** война шла ещё **~20 лет**; боги ковали **сервиторов-полководцев** из душ воинов (вели армии); изобрели **ритуал границ мира** (= «защита от демонов», снять можно только изнутри; ≠ сковывание Нечто); долго истребляли демонские культы; смертная вера началась как **ордены охотников** → религии. Темпус прозевал момент призыва Нечто; петля невежества → помогло Катастрофе.
- [x] ✅ **Подземные народы** чтут богов (из [[Эпоха богов]]) — раскрыто в [[Народы]]: дварфы (горы, верхние слои) + дроу (глубина); практика «аасимар на троне» у них не прижилась.
- [x] ✅ Модель **посмертия — F**: карманы богов + **Глубина** (старше богов). Сервиторы из душ; дикая нежить из потерянных душ. Детали — [[Загробие]].
