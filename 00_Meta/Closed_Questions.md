## Космология / метафизика
- [x] ✅ Природа **[[Сердце|Сердца]]** — природный **родник жизни и магии**, питается многомирьем; **с Нечто не связан** (ни родства, ни цикла). Физика — тайна для игроков навсегда.
- [x] ✅ Механизм **сковывания** — боги в цейтнот **бросили себя клеткой-изоляцией** вокруг Нечто в городе; цена — стали узниками затычки и стираются в неё (часы кампании). См. [[Катастрофа]].
- [x] ✅ Связь **Нечто и Сердца** — её нет; роднит лишь место (Нечто в руинах **над** Сердцем).
- [x] ✅ **Пра-история (до богов):** внешний враг — **демоны из ближнего мира**, вторгшиеся по «дороге демонов». Пятёрка отняла у их лидера **сифон** (демонский инструмент выпивания миров → [[Опустошитель]]), прошла к [[Сердце|Сердцу]], **вознеслась** и уже божественной силой отогнала демонов и **заперла дорогу**. Сердце — родник, не оружие (тема №1, см. [[Архитектурные_приоритеты]]). Истребление прорвавшихся заняло **долгие годы**; горстка демонов уцелела, затаилась и осмелела после Катастрофы → [[Культ Пепельной Матери]]. Осталось: **роль демонов** (минорное участие/отсылка в одной арке; не основная тема). ✅ Связь с ancestries решена → [[Народы]] (тифлинги = след демонов; дроу = порабощённые демонами эльфы).
- [x] ✅ **Кап — только на divine-магию, 3-я ячейка**; arcane/primal/occult не тронуты. Остаточная divine идёт **напрямую от ослабших богов** (инстинктивно питают жрецов); угасала постепенно, к лимиту пришла недавно. PC-жрец превышает кап **силой [[Проводник|Проводника]]** (думая, что это бог). См. [[Метафизика магии]], [[Пантеон]] т.2/т.7.

- [x] ✅ **Чем боги занимались и каковы их цели** — все 3 топика решены (тема №3 «природа и цели богов»):
  - [x] ✅ **№1 Становление и вознесение:** отряд в войну с демонами добыл [[Опустошитель|сифон]] (из ставки демонов; знание — от перебежчика [[Кадреш|Отступника]]), [[Время (бог)|Темпус]] + Отступник доработали его, **сознательно** вознеслись у [[Сердце|Сердца]], чтобы спасти мир. Founding-цель = оборона от демонов.
  - [x] ✅ **№2 Сразу после вознесения:** война шла ещё **~20 лет**; боги ковали **сервиторов-полководцев** из душ воинов (вели армии); изобрели **ритуал границ мира** (= «защита от демонов», снять можно только изнутри; ≠ сковывание Нечто); долго истребляли демонские культы; смертная вера началась как **ордены охотников** → религии. Прецедент: маги-победители попытались вскрыть границу, чтобы добить демонов в их мире → толчок к стиранию (→ №3). Подробно → [[Демоническая война]].
  - [x] ✅ **№3 После снятия угрозы:** **[[Эпоха богов]]** ~2000 лет — дозачистка (~200 лет), ордены→религии, **покорение мира** (вера всеобщая, но не теократия везде; даже подземные народы), **стирание истории** («абсолютная вера»), заточение [[Кадреш|Отступника]] → [[Тюрьма-остров]]. **Окостенение:** долгий век → каждый ушёл в **личный проект** (Темпус — пророчества; Жизнь — сад; Справедливость — армия против демонов; Смерть — Глубина; Удача — искусство и хождение среди людей) = первородный грех. Темпус прозевал момент призыва Нечто; петля невежества → помогло Катастрофе.
- [x] ✅ **Подземные народы** чтут богов (из [[Эпоха богов]]) — раскрыто в [[Народы]]: дварфы (горы, верхние слои) + дроу (глубина); практика «аасимар на троне» у них не прижилась.
- [x] ✅ Модель **посмертия — F**: карманы богов + **Глубина** (старше богов). Сервиторы из душ; дикая нежить из потерянных душ. Детали — [[Загробие]].
- [x] ✅ **Редкость воскрешения**: душу ловят до Глубины; размытая дорога делает это рискованным, PC — особые.
- [x] ✅ Сервиторов делают **все пятеро**; критерий зависит от бога (в нужде — любые души); сервитор **теряет память**.
- [x] ✅ **Глубина (только мастер):** души → чистая жизненная сила → возврат в мир через [[Сердце]] (цикл). Игрокам — полная тайна.
- [x] ✅ Мир умирает **от Нечто** (дрейф/разрыв дороги душ), **не** от убыли жизненной силы. Сердце питают многие миры, доля богов — капля. Грех богов ≠ смерть мира (выбор остаётся трудным).
- [x] ✅ Источник силы Сердца игроки **не узнают никогда** (мастеру: многомирье).
