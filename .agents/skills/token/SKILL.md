Сделай токен для NPC, названного в запросе (ниже — `<Имя NPC>`).

Полный процесс и все параметры — в `00_Meta/Пайплайн — токены NPC.md`. Следуй ему.
Портрет генерит Ferrus во внешнем генераторе (Nano Banana или ChatGPT) по твоим промптам — или ты сам через
Codex (шаг 2c пайплайна); прозрачность и срез — локальными скриптами. На шагах с
выбором ОСТАНАВЛИВАЙСЯ.

1. **Облик.** Прочитай `04_NPCs/<Имя NPC>.md` (у текстурных NPC — файл региона). Если `## Образ`
   = TBD — предложи 2–4 концепта (роль/регион/палитра), дождись выбора, зафиксируй, сними пункт
   из `00_Meta/Open_Questions.md`.

2. **Портрет.** Спроси, где генерим — Nano Banana, ChatGPT или Codex. Промпт по канону: **tight bust portrait,
   three-quarter view, head and upper chest only, cropped at mid-chest**, явная этничность/возраст, черты лица,
   наряд/палитра, аксессуар у лица/плеч (не в руках). Правки (одежда и т.п.) — как ПРАВКУ загруженного кадра
   (генератор держит лицо между итерациями), не новой генерацией.
   - Nano Banana / ChatGPT: дай промпт, Ferrus кладёт кадр в `99_Sketches/tokens/_work/<slug>/`.
   - Codex: генерируй сам — `codex exec -s workspace-write -C <волт> "<промпт> … скопируй в _work/<slug>/…"`;
     правки — новым `codex exec` с `-i <кадр>` («ПРАВКА прикреплённого изображения»). В самом Codex — встроенным
     инструментом напрямую. Покажи кадр и жди одобрения. Подробно — шаг 2c пайплайна.

3. **Прозрачный фон — путь A (основной: ChatGPT или Codex).** Последней правкой попроси прозрачный фон: убрать фон
   целиком, PNG с прозрачностью, лицо/одежду/позу/капюшон/волосы не менять, голова и плечи целиком в кадре.
   Проверь: `python3 00_Meta/scripts/remove_bg.py check <файл>` — exit 0, верхние углы прозрачны (пометка «тело
   почти непрозрачно» у GPT Image — норма, `token_frame.py` дотянет); покажи
   `<файл>_check.png` (фигура на пурпуре) и посмотри кромку капюшона и волос.
   Нет альфы (exit 1), грязная или рваная кромка, или портрет из Nano Banana → **путь B**.

4. **Путь B (запасной).** Последней правкой в генераторе — **плоский белый фон** (КРИТИЧНО): бесшовный белый студийный,
   без сцены/предметов/дыма/градиента, тень за спиной убрать, ровный фронтальный свет (тёмный капюшон отделяется
   от белого чёткой кромкой), голова+плечи целиком с запасом; лицо/одежду/позу не менять. Затем
   `python3 00_Meta/scripts/remove_bg.py cut <кадр> <вырез.png>` (BiRefNet-ToonOut, ONNX, CPU).
   Проверь сводку и `<вырез>_check.png` на пурпуре — не на обычном превью, оно флэттит прозрачность.
   Нет `onnxruntime` → `pip install --user onnxruntime`. Модель (~1 ГБ) скрипт качает в `_models/` сам; без сети
   он выдаст ссылку — попроси Ferrus скачать. Падает по памяти в песочнице агента — попроси Ferrus запустить команду у себя.

5. **Композит.** Высокий кадр (до пояса/кистей) — сначала обрежь до головы+груди (обнули альфу ниже
   линии рук), иначе голова мелкая. `00_Meta/scripts/token_frame.py --canvas 512`, подбери
   `--height-frac` (~0.82–0.90) и `--cap-frac` (~0.55–0.60); низ срезается по кольцу. 2–3 варианта,
   превью, **дай выбрать**. Кадр: разрыв кольца только сверху/по бокам; бюст, не одно лицо.

6. **Экспорт.** Финал (out_subject, БЕЗ кольца) → `99_Sketches/tokens/<Имя NPC>.webp` (q80,
   **только webp**). Сырьё → `99_Sketches/tokens/_work/<slug>/` (в .gitignore). Запиши `GEN_PARAMS.md`
   (образ, генератор, промпты + правка фона, путь A/B, финальная команда). Проверь read-only:
   `git check-ignore 99_Sketches/tokens/<Имя NPC>.webp` (пусто = попадёт в гит). **НЕ** `git add -n` — берёт `.git/index.lock`.

7. **Напомни Foundry-настройки:** Subject Texture = файл, Ring Enabled, Lock Artwork Rotation,
   Fit Mode = Standard.

Покажи финал и жди подтверждения.
